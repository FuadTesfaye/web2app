  • ✔ Android Studio Ready

Standalone Windows app wrapper leveraging MS Edge / Chromium App mode with custom manifests, launch scripts, and automated installer shortcuts.

  • ✔ launch.bat & launch.ps1
  • ✔ start.vbs (Silent Window)
  • ✔ install.bat (Desktop Icon)

Pure TypeScript packaging engine builds ready-to-install binary .deb packages, desktop entries, and icon registries on any operating system.
